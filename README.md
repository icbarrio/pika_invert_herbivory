# Invertebrate herbivory and pika foraging choices
This repository contains data and code for the analyses presented in the paper "Effects of invertebrate herbivory on forage selection of collared pikas (Ochotona collaris) in alpine meadows" currently under review.

Our study investigates the foraging preferences of collared pikas (Ochotona collaris) of plants previously damaged by invertebrate herbivores. We focus on three common forage species that represent three plant functional groups: evergreen dwarf shrubs (Dryas octopetala), forbs (Polygonum viviparum) and deciduous dwarf shrubs (Salix spp.).
